# AI4SE Coding Agent Harness v2.0.3

## 更新内容

- 每次 Provider 调用都会收到实际运行平台（`win32`、`linux` 或 `darwin`）。
- 已知文件必须使用内建 `read_file`，不再建议 `cat`、`type` 或 `Get-Content`。
- 明确禁止模型选择 `cmd`、PowerShell、bash、sh 等会被安全策略拒绝的 Shell。
- 缺少 `list_files` Action 时，统一使用受审批的 Node.js `node:fs` API 列目录，保持跨平台。

## 软件包

- 文件名：`ai4se-harness-2.0.3.tgz`
- 标签：`v2.0.3`
- 安装：`npm install --global .\ai4se-harness-2.0.3.tgz`
- 离线检查：`ai4se-harness smoke`
- SHA-256：创建 Release 时以最终流水线产物的校验值为准

## 平台说明

- Node.js 24 下的离线 smoke、核心 Harness 和分发包结构支持 Windows、Linux 与 macOS。
- Windows 11 提供普通无参数首次初始化和当前用户系统凭据保险库。
- Linux/macOS 的真实 Provider 验收使用 README 中的主密码兼容入口；不会退回明文保存 Key。

## 验收重点

1. 在任意支持 Node.js 24 的平台运行 `ai4se-harness smoke`。
2. 在 Windows 普通会话中询问“目录代码是做什么的”，确认模型不会选择 `ls`、`cat`、`cmd.exe` 或 PowerShell。
3. 在 Linux/macOS 使用兼容入口时确认系统提示显示对应平台，并继续优先使用 `read_file` 与 Node.js `node:fs`。

完整能力、限制与安全说明见项目 README。

# AI4SE Coding Agent Harness v2.0.1

## 更新内容

- `ai4se>` 提示符与用户输入显示在同一行。
- 用户提交内容后，任务状态和模型输出前增加空行。
- 每轮输出结束后，下一次提示符前保留清晰间距。
- Harness 功能、安全边界、配置格式和 Memory 数据格式均未改变。

## 软件包

- 文件名：`ai4se-harness-2.0.1.tgz`
- 标签：`v2.0.1`
- 安装：`npm install --global .\ai4se-harness-2.0.1.tgz`
- 离线检查：`ai4se-harness smoke`
- SHA-256：创建 Release 时以最终流水线产物的校验值为准

## 使用

进入希望 Agent 操作的项目目录，运行：

```powershell
ai4se-harness
```

首次在该工作区启动时只填写服务地址、隐藏 API Key 和模型名称；以后直接运行同一命令即可。

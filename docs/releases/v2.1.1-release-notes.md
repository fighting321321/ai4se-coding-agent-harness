# AI4SE Coding Agent Harness v2.1.1

本版本保留 v2.1.0 的全部 Harness 可用性修复，并将课程最终公开分发入口迁移到 GitHub Release。

## 核心能力

- 脱敏后的文件内容和成功命令输出最多保留 12,000 字符进入下一轮 Observation。
- 连续重复读取同一个未修改文件时不再重复执行工具。
- CLI 区分 Provider 限流、凭据无效、网络错误和服务端错误。
- 保留 PathGuard、Policy、逐次 Approval、Trace v3、长期 Memory、Skill、MCP 教学适配、Hook、子 Agent、Sensor 与单文件 Checkpoint。

## 获取与验证

- Release：https://github.com/fighting321321/ai4se-coding-agent-harness/releases/tag/v2.1.1
- 文件名：`ai4se-harness-2.1.1.tgz`
- 安装：`npm install --global .\ai4se-harness-2.1.1.tgz`
- 离线检查：`ai4se-harness smoke`
- 真实使用：在待处理项目目录执行 `ai4se-harness`

## SHA-256 与验收重点

Release 页面应填写上传 tarball 的 SHA-256。验收时重点检查离线 smoke、长文件读取、重复读取纠正、Provider 限流提示、逐次权限确认，以及 API Key 不进入源码、Release 或日志。

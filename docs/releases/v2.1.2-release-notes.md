# AI4SE Coding Agent Harness v2.1.2

本版本是基于 v2.1.1 的稳定性补丁，不扩展产品范围，重点修复真实 Agent 任务中发现的恢复、敏感动作判断和冷启动测试问题。

## 修复内容

- 将日志的宽泛脱敏与动作级高置信敏感信息判断分离，减少安全写入动作被误判为 `SENSITIVE_ACTION`。
- 将 `PATH_NOT_FOUND` 纳入可恢复反馈，使 Agent 能根据错误提示修正路径并继续执行。
- 对连续重复的相同恢复动作增加停止保护，避免无效循环耗尽步骤。
- 测试环境无需预先生成 `packages/harness/dist` 即可解析 Harness 源码，修复全新解压目录的冷启动测试。
- 测试夹具允许明显的假凭据，同时继续阻止当前会话的真实 API Key 进入动作、Checkpoint、日志或 Git。
- 忽略本地 `.ai4se` 运行产物，避免开发工具将临时验收文件当成待提交源码。

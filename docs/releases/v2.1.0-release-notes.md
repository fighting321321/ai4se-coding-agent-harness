# AI4SE Coding Agent Harness v2.1.0

本版本修复真实交互测试中发现的长文件反馈与错误提示问题。

## 主要改进

- 脱敏后的文件内容和成功命令输出最多保留 12,000 字符进入下一轮 Observation，能够直接分析课程规模的源码文件。
- 连续重复读取同一个未修改文件时不再重复执行工具，而是要求模型使用已有 Observation 或选择其他文件。
- CLI 区分 Provider 限流、凭据无效、网络错误和服务端错误，不再全部显示为笼统的“Provider 调用失败”。
- 保留原有 PathGuard、Policy、Approval、Trace、Memory 与凭据脱敏边界。

## 获取与验证

- 文件名：`ai4se-harness-2.1.0.tgz`
- 标签：`v2.1.0`
- 安装：`npm install --global .\ai4se-harness-2.1.0.tgz`
- 离线检查：`ai4se-harness smoke`
- 真实使用：在待处理项目目录执行 `ai4se-harness`

## SHA-256 与验收重点

Release 创建后应以 CI 下载的 tarball 计算 SHA-256，并填写到 Release 页面。验收时重点检查长文件读取、重复读取纠正、Provider 限流提示、离线 smoke，以及 API Key 不进入源码、Release 或日志。

## 可直接粘贴的 Release 说明

这是课程项目的教学级完整 Coding Agent Harness v2.0.0。它提供连续终端会话、确定性上下文压缩、脱敏长期 Memory、工作区规则、渐进 Skill、教学级 Mock MCP、生命周期 Hook、串行受限子 Agent、写后 Sensor、受控单文件 Checkpoint，以及可兼容读取旧版记录的 Trace v3。

核心机制均由离线 deterministic mock/stub 验证；真实 Provider 只作为人工补充验收。CLI 仅支持 Node.js 24，普通 Windows 流程在当前目录无参数启动，首次只填写服务地址、隐藏 API Key 和模型名称。API Key 进入当前 Windows 用户保护的本地安全存储，不写入普通配置、日志、Trace、Memory、命令参数或 Git。

学校 GitLab 未提供可用公开 Pages 地址，因此本项目采用助教允许的“CLI + GitLab Release”交付。WebUI 只保留本地模式与静态 mock 源码，不提供线上服务。

已知限制：单 Provider；MCP 仅为教学适配与离线 mock；子 Agent 串行；Checkpoint 只恢复明确快照的 UTF-8 单文件，不回滚命令、MCP、网络或系统副作用；不包含数据库、多用户、Docker、SSE 或生产级调度。

## 助教验收步骤

1. 安装 Node.js 24 与 pnpm 11.14.0。
2. 下载附件并核对页面所列 SHA-256。
3. 执行 `pnpm add --global .\ai4se-harness-2.0.0.tgz`。
4. 执行 `ai4se-harness smoke`，应输出 `AI4SE Harness 离线 smoke：completed`。
5. 进入一个待测试项目目录，直接执行 `ai4se-harness`。
6. 首次只填写服务地址、隐藏 API Key 和模型名称；不编辑 JSON，不设置本地保护密码。
7. 连续提出两项相关任务，确认后一题能引用前文；使用 `/status`、`/model`、`/memory` 和 `/trace` 检查状态与脱敏记录。
8. 使用 `/exit` 安全退出，再次运行 `ai4se-harness`，确认无需重复填写 Key，且相关任务可检索已固化 Memory。
9. 验收结束后按 Provider 平台流程撤销测试 Key；项目 CLI 当前没有面向普通系统保险库的独立清除命令，若需清除本机保险库文件应由负责人按平台说明人工处理。

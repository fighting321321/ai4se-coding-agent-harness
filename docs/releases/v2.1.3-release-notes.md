# AI4SE Coding Agent Harness v2.1.3

v2.1.3 是基于 v2.1.2 的 Provider 协议恢复补丁，不改变工具、路径、审批或凭据安全边界。

## 修复内容

- 当 OpenAI-compatible Provider 返回无法解析为单个 Action JSON 的内容时，Agent 会把严格格式要求作为脱敏 Observation 回灌，并在剩余步骤与共享预算允许时自动纠正一次。
- 自动纠正只允许一次；连续第二次无效会以 `provider_action_invalid` 停止，不会无限请求或重复已经完成的工具副作用。
- CLI 摘要现在区分 Action JSON、Provider 响应、HTTP、网络、鉴权、限流与服务端错误，不再统一显示含糊的“Provider 调用失败”。
- 每次 Provider 调用前重置 Trace 的 Assistant 与 Approval 临时状态，避免 Provider 失败条目沿用上一项写入动作的审批结果。

## 验收重点

- 首次 `PROVIDER_ACTION_INVALID` 后，Trace 记录 `running` 的格式纠正 Observation，且审批状态为 `not_required`。
- 下一次返回合法 Action 时任务可以继续完成，已成功写入的文件不会重复写入。
- 连续第二次返回无效 Action 时任务在两次 Provider 调用后确定性停止。
- 真实 Provider 回归应覆盖较长 `write_file` 任务、Trace 脱敏和一次受限纠正行为。

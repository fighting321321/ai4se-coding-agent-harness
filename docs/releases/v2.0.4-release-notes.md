# AI4SE Coding Agent Harness v2.0.4

## 更新内容

- 成功命令的 stdout/stderr 会进入下一轮 Observation，不再只返回退出码。
- 输出在回灌前经过 API Key 脱敏，并限制为 160 字符。
- 没有输出的成功命令仍稳定返回 `pass: command exited 0`。
- 修复列目录成功后模型看不到文件名、反复执行直到 `max_steps` 的问题。

## 软件包

- 文件名：`ai4se-harness-2.0.4.tgz`
- 标签：`v2.0.4`
- 安装：`npm install --global .\ai4se-harness-2.0.4.tgz`
- 离线检查：`ai4se-harness smoke`
- SHA-256：创建 Release 时以最终流水线产物的校验值为准

## 验收重点

进入包含若干源文件的目录后询问“当前目录中的代码是做什么的”。模型应使用受审批的 Node.js `node:fs` 命令列目录，在下一步获得文件名，随后通过 `read_file` 阅读源文件，而不是重复列目录到 `max_steps`。

完整能力、限制与安全说明见项目 README。

# AI4SE Coding Agent Harness v2.0.2

## 更新内容

- 未写入持久白名单的普通命令不再直接失败，而是显示完整命令并逐次请求用户批准。
- 用户批准只对当前动作有效，不会静默扩大后续任务权限。
- Shell 解释器、删除类命令、敏感路径和工作区越界动作仍在副作用前固定拒绝。
- 保留 v2.0.1 的同行提示符与输入输出留白改进。

## 软件包

- 文件名：`ai4se-harness-2.0.2.tgz`
- 标签：`v2.0.2`
- 安装：`npm install --global .\ai4se-harness-2.0.2.tgz`
- 离线检查：`ai4se-harness smoke`
- SHA-256：创建 Release 时以最终流水线产物的校验值为准

## 验收重点

让 Agent 执行普通脚本时，CLI 应先显示完整命令：

```text
动作 run_command，命令 "python" "add.py"。是否批准？[y/N]
```

输入 `y` 后只执行本次命令；输入其他内容则拒绝。完整能力、限制与安全说明见项目 README。
